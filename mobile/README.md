# Happy Mobile

Application Android / iOS de Happy (Expo SDK 57, React Native, TypeScript, expo-router, NativeWind, Supabase).

```bash
node scripts/setup.js   # crée .env et .npmrc
npm install
npx expo start
```

Tout est expliqué dans **[GUIDE.md](./GUIDE.md)** : installation, architecture, fonctionnement par rôle, scénario de démonstration, publication avec EAS et dépannage.
